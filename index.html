OpenSSH client not found

hosterm runs the real ssh/sftp binaries that come with your OS. Without them, connecting to hosts and transferring files cannot work — editing ~/.ssh/config keeps working.

Install — Windows Settings

Settings → Apps → Optional features → View features → search for “OpenSSH Client” → Install. (Windows 10 1809+ and Windows 11.)

Install — PowerShell (run as Administrator)

The command installs the Windows capability “OpenSSH.Client” and needs an elevated PowerShell.

More details: Microsoft OpenSSH docs (steps above work offline)
