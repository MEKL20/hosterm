Property-style: argv builder = SATU sumber argv, asserted "contains BatchMode, never forbidden flags" untuk semua kombinasi mode×alias.
2. **Smoke (FL-2/FL-3/FL-4):** mock invoke map + `__emitTauri` replay fixture §12.3 VERBATIM (copy-paste dari SDD — tidak diedit; perubahan fixture = perubahan §12.3 = addendum architect). 3. **Grep gates (verify loop, FL-4 canon):** `sh -c|bash -c|cmd /C` di jalur fleet = 0 (INV-14/NFR-FL4); string sidecar tak pernah muncul di output fleet (INV-15/NFR-FL7); dependency diff `Cargo.toml`/`package.json` = 0 entries (NFR-FL1) — dicek manual saat review FL-1.
4. **Build:** `npm run build` 0 TS error tiap frontend unit; `cargo test --lib` tiap FL-1+ review.
5. **Manual Windows matrix (release gate, BUKAN CI — R-FL-10, SEC-5 WAIVED):** sebelum tag berikutnya, fleet di-run nyata: 3 host key-auth + 1 unknown-host-key (harap `fail` 255 + pesan actionable, BUKAN timeout/auto-accept — OQ-2 CLOSED) + 1 password host (harap `skipped` reason persis) + cek 0 window flash (`CREATE_NO_WINDOW`).
